# Report

## Summary

This report covers the validation of markdown formatting across the agentwrap-smoke project. All markdown files were checked for structural correctness, broken links, and adherence to the project's style guidelines. No critical issues were found; minor formatting inconsistencies were noted in 3 files.

## Details

The validation process scanned 12 markdown files in the repository. Each file was checked against the following criteria: heading hierarchy (no jumps from h1 to h3), list formatting consistency, code block language annotations, and relative link validity. Three files (`docs/guide.md`, `examples/README.md`, and `api/endpoints.md`) contained minor issues such as inconsistent indentation in nested lists and missing blank lines around code blocks. All issues have been classified as low severity and do not affect rendering. No broken internal links were detected.
